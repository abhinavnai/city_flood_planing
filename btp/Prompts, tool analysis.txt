API and their purpose:


Nominatim API (Open Street map)  Link

* Purpose: Geocoding (convert place names to coordinates) & reverse geocoding (coordinates to addresses).

* Used for: Finding the location and bounding box of “Jodhpur” or other cities/wards mentioned in prompts.




Bhuvan Disaster API (external; flood/risk data)

   * Purpose: Provides real-time disaster layers such as flood extent maps.

   * Used for: Overlaying flood areas on top of the OSM map to assess impacts.


Overpass API
      * Purpose: Query OpenStreetMap data using filters (e.g., hospitals, roads, buildings).

      * Used for:

         * Fetching POIs like hospitals, schools, shelters.

         * Getting road networks, land use, administrative boundaries, and building footprints.
